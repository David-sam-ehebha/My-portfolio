# **App Name**: DevFolio

## Core Features:

- Project Showcase: A dedicated section to display individual projects with images, detailed descriptions, and links to live demos or repositories.
- About Me Page: A professional section for the user to introduce themselves, share their story, and highlight their unique value proposition.
- Skills Overview: Clearly categorized display of the user's technical and soft skills, possibly with proficiency indicators.
- Contact Form: A simple, functional form allowing visitors to send messages directly to the portfolio owner.
- AI-Powered Project Description Assistant: An integrated tool that helps users generate concise and compelling descriptions for their portfolio projects using generative AI.

## Style Guidelines:

- Primary color: A sophisticated, muted violet (#5229A3) chosen to convey professionalism and thoughtful innovation, balancing depth with approachability.
- Background color: A very light, almost white lavender (#F4F1F8) to ensure high readability and a clean, serene visual foundation, while maintaining a subtle connection to the primary hue.
- Accent color: A vibrant yet harmonious sky blue (#74AFEE), analogous to the primary color, used to draw attention to interactive elements and highlights without overpowering the main content.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, structured, and tech-inspired aesthetic, ideal for strong, concise headings.
- Body font: 'Inter' (sans-serif) to ensure optimal readability for longer texts, providing a neutral and clear presentation for project descriptions and other content.
- Utilize minimalist line icons that align with a modern, clean design ethos. Icons should clearly communicate function without adding visual clutter.
- Implement a responsive, grid-based layout prioritizing clean lines and ample whitespace to create a spacious and uncluttered user experience, effective on all device sizes.
- Incorporate subtle hover effects on interactive elements and smooth transitions for page changes, providing elegant feedback and enhancing the overall user flow without distraction.
